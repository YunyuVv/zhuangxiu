# 项目交接入口

最后核查：2026-11-09（Asia/Shanghai）。本目录用于跨时间、跨 AI Agent 的开发和排障交接，纳入版本管理后随仓库传递。

## 接手顺序

1. [项目概览](01-项目概览.md)：理解项目定位、范围和架构。
2. [当前状态](02-当前状态.md)：了解实现进度、验证边界与未提交改动。
3. [任务与问题台账](05-任务与问题台账.md)：找本次目标、编号和验收条件。
4. [代码与运行地图](03-代码与运行地图.md)：定位调用链、配置和检查命令。
5. [开发记录](开发记录/2026-11-09-01-项目基线与交接体系.md)：先读最近相关记录，了解已做过什么、还卡在哪里。
6. 开始前核对实际 Git 和源码；结束前按 [记录规范](04-记录规范.md) 更新。

## 目录职责

```text
docs/项目交接/
├── README.md                    # 唯一交接入口
├── 01-项目概览.md               # 定位、范围、架构；方向变化时更新
├── 02-当前状态.md               # 当前快照；实现或验证结果变化时更新
├── 03-代码与运行地图.md         # 调用链、环境、排障入口
├── 04-记录规范.md               # 何时记、怎么记、如何接手
├── 05-任务与问题台账.md         # 稳定编号、状态、验收条件、记录链接
├── 开发记录/                    # 按日期追加，保留过程和证据
└── 模板/                       # 开发记录、Bug 记录、决策记录
```

当前规模采用 Markdown 即可，不必先引入新的管理系统。Git 保存代码差异，台账保存待办和状态，开发记录保存原因、验证与下一步；重要决策单独记录。原始聊天无需全部复制，也不能替代结果记录。

## 下次交给 AI 的提示词

```text
请继续这个装修记录项目。先阅读根目录 AGENTS.md 和 docs/项目交接/README.md，
再读取当前状态、任务与问题台账以及目标事项相关的最新开发记录。
核对当前 Git 状态和源码，不要覆盖已有改动。
本次目标是：<填写任务/Bug 编号和具体目标>。
实施前确认验收条件，完成后记录实际验证、剩余问题和下一步，并同步台账与当前状态。
```

具体任务、数据环境和验收目标仍由当次用户指令确定；本文不自动授权部署或修改外部数据。
