## 3. 接口清单（REST + JWT，前缀 `/api`）

统一响应体：`{ code, message, data, timestamp }`；分页：`page`（从 0）、`size`、`sort`。
鉴权：除 `/auth/*` 外，Header 带 `Authorization: Bearer <token>`；无/失效返回 401。

### 3.1 账户
| 方法 | 路径 | 请求 | 响应 |
| --- | --- | --- | --- |
| POST | `/api/auth/register` | `{username, password, nickname?}` | `{token, user}` |
| POST | `/api/auth/login` | `{username, password}` | `{token, user}` |
| POST | `/api/auth/logout` | — | `{success}` |

### 3.2 项目
| 方法 | 路径 | 请求 | 响应 |
| --- | --- | --- | --- |
| GET | `/api/projects?page=&size=` | — | 项目列表（含概览摘要：已花、完成度） |
| POST | `/api/projects` | `{name, address, totalBudget, startDate, expectedEndDate, area?}` | 新建项目（自动初始化 8 阶段） |
| GET | `/api/projects/{id}` | — | 项目详情 + 阶段列表 |
| PUT | `/api/projects/{id}` | 同 POST 字段（部分更新） | 更新后项目 |
| DELETE | `/api/projects/{id}` | — | 删除（级联删阶段/花销/资料） |

### 3.3 阶段
| 方法 | 路径 | 请求 | 响应 |
| --- | --- | --- | --- |
| GET | `/api/projects/{id}/phases` | — | 阶段列表（含 `budget`、`status`、起止日期、照片数），按 `sortOrder` 排序 |
| POST | `/api/projects/{id}/phases` | `{name, sortOrder?, startDate?, endDate?, budget?, note?}` | 新增阶段（末尾追加；`name` 必填） |
| PUT | `/api/projects/{id}/phases/{phaseId}` | `{name?, sortOrder?, status?, startDate?, endDate?, budget?, note?}` | 更新阶段（改名/排序/状态/预算） |
| DELETE | `/api/phases/{phaseId}` | — | 删除阶段（**级联清理其下花销与子项**；二次确认前端做） |

### 3.3.1 阶段子项（自定义子步骤/检查项）

| POST | `/api/phases/{phaseId}/tasks` | `{name, sortOrder?, note?}` | 新增子项（`name` 必填） |
| PUT | `/api/tasks/{taskId}` | `{name?, sortOrder?, done?, note?}` | 更新子项（改名/排序/勾选完成） |
| DELETE | `/api/tasks/{taskId}` | — | 删除子项 |

### 3.4 花销

## 4. 数据表设计（Flyway `V1__init.sql`，PostgreSQL）

```sql
-- 用户
CREATE TABLE users (
    id            BIGSERIAL PRIMARY KEY,
    username      VARCHAR(64) NOT NULL UNIQUE,
    password_hash VARCHAR(100) NOT NULL,
    nickname      VARCHAR(64),
    created_at    TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- 项目/房屋档案
CREATE TABLE projects (
    id                  BIGSERIAL PRIMARY KEY,
    user_id             BIGINT NOT NULL REFERENCES users(id),
    name                VARCHAR(128) NOT NULL,
    address             VARCHAR(255),
    total_budget        NUMERIC(14,2) NOT NULL DEFAULT 0,
    area                NUMERIC(10,2),
    start_date          DATE,
    expected_end_date   DATE,
    created_at          TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_projects_user ON projects(user_id);

-- 阶段（固定 8 标准工序，sort_order 定序）
CREATE TABLE phases (
    id          BIGSERIAL PRIMARY KEY,
    project_id  BIGINT NOT NULL REFERENCES projects(id),
    name        VARCHAR(64) NOT NULL,
    sort_order  INT NOT NULL,
    start_date  DATE,
    end_date    DATE,
    status      VARCHAR(16) NOT NULL DEFAULT 'NOT_STARTED', -- NOT_STARTED/IN_PROGRESS/DONE
    budget      NUMERIC(14,2) NOT NULL DEFAULT 0,
    note        TEXT,
    extra       JSONB
);
CREATE INDEX idx_phases_project ON phases(project_id);

-- 花销
CREATE TABLE expenses (
    id           BIGSERIAL PRIMARY KEY,
    project_id   BIGINT NOT NULL REFERENCES projects(id),
    phase_id     BIGINT NOT NULL REFERENCES phases(id),
    name         VARCHAR(128) NOT NULL, -- 物品/器材名称（必填，与 category 区分）
    category     VARCHAR(32) NOT NULL, -- 设计费/材料/人工/家具家电/其他
    amount       NUMERIC(14,2) NOT NULL,
    pay_method   VARCHAR(32),
    occurred_at  DATE NOT NULL,
    note         TEXT,
    created_at   TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_expenses_project ON expenses(project_id);
CREATE INDEX idx_expenses_phase ON expenses(phase_id);

-- 资料/图片（多态关联 ref_type + ref_id）
CREATE TABLE attachments (
    id          BIGSERIAL PRIMARY KEY,
    project_id  BIGINT NOT NULL REFERENCES projects(id),
    ref_type    VARCHAR(32) NOT NULL, -- PROJECT/PHASE/EXPENSE
    ref_id      BIGINT NOT NULL,
    file_url    VARCHAR(512) NOT NULL,
    file_type   VARCHAR(32)
);
CREATE INDEX idx_attachments_ref ON attachments(ref_type, ref_id);
```

#### 新增迁移 `V2__guide.sql`（公开内容；**不动已执行的 V1**）

> `V1__init.sql` 已在测试/生产库执行过，新增表必须走**新的 V2 迁移脚本**，绝不能回改 V1，否则 Flyway 校验失败。

```sql
-- 装修指南（公开内容，对应 8 标准阶段，不关联 user_id）
CREATE TABLE guides (
    id          BIGSERIAL PRIMARY KEY,
    stage_key   VARCHAR(32) NOT NULL UNIQUE, -- CHAI_GAI/SHUI_DIAN/NI_WA/MU_GONG/YOU_QI/AN_ZHUANG/RUAN_ZHUANG/YAN_SHOU
    title       VARCHAR(64) NOT NULL,
    summary     TEXT,        -- 做什么（轻量 P0）
    duration    VARCHAR(32), -- 大概周期
    cost_ratio  NUMERIC(5,2),-- 花费占比 0~1
    sort_order  INT NOT NULL
);
CREATE TABLE guide_details (
    id          BIGSERIAL PRIMARY KEY,
    guide_id    BIGINT NOT NULL REFERENCES guides(id),
    section     VARCHAR(32), -- BUY/WHO/PITFALL/BUDGET（P1 完整攻略）
    content     TEXT,
    sort_order  INT
);
CREATE INDEX idx_guide_details_guide ON guide_details(guide_id);
```

> 8 条阶段指南数据由种子脚本/`data.sql` 初始化（`stage_key` 对应标准阶段，仅作通用参考）；`GUIDE_DETAILS` 初期可空。

#### 新增迁移 `V3__phase_custom.sql`（阶段自定义 + 子项 + 花销物品名；**不动已执行的 V1/V2**）

> 阶段自定义仅需改初始化逻辑与补接口，`phases` 表结构无需变动（`name` 本就自由文本、`sort_order` 已支持排序）。本迁移只补两件事。

```sql
-- 阶段内子项/子步骤（用户自定义检查项，无金额）
CREATE TABLE phase_tasks (
    id          BIGSERIAL PRIMARY KEY,
    project_id  BIGINT NOT NULL REFERENCES projects(id),
    phase_id    BIGINT NOT NULL REFERENCES phases(id),
    name        VARCHAR(128) NOT NULL,
    done        BOOLEAN NOT NULL DEFAULT FALSE,
    sort_order  INT NOT NULL DEFAULT 0,
    note        TEXT,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_phase_tasks_phase ON phase_tasks(phase_id);

-- 花销补充物品/器材名称（必填，与 category 区分）
ALTER TABLE expenses ADD COLUMN name VARCHAR(128) NOT NULL DEFAULT '';
```

> 注：`expenses.name` 因含存量数据，用 `DEFAULT ''` 兜底；上线后可由运营/用户补填历史记录名称。

> 金额统一 `NUMERIC(14,2)`，禁用浮点；阶段 `status` 枚举三态；`attachments` 用多态关联支持挂项目/阶段/花销。

## 5. 技术依赖

- **后端**：Spring Boot 4 + Maven；Spring Security（JWT）、Spring Data JPA、Flyway、Spring Data Redis、**Springdoc OpenAPI**（自动生成接口文档）；各组件（含 JSON 序列化、JWT、Bean Validation、OpenAPI、Redis 序列化、JPA/Flyway 数据库操作）均须 **GraalVM Native 兼容**（反射/动态代理用 `@RegisterReflection` 或 `RuntimeHints` 声明）；PostgreSQL JDBC 需静态配置。
- **前端**：Next.js（App Router + TS），**pnpm** 管理依赖；`fetch`/axios；状态管理用 React Context 或轻量 store（如 Zustand）；图片压缩用浏览器 Canvas 或 `browser-image-compression`。
- **图床**：前端 `fetch` 直传 `api.imgbb.com`，Key 来自 `/api/attachment/upload-key`。
- **基础设施**：Docker（PG + Redis），GraalVM Native Image（CI/生产构建）。

## 6. 风险清单

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| **Native 反射** | JPA 实体、Jackson DTO、JWT 工具类在 native 下缺反射提示会启动失败 | 用 `@RegisterReflection` / `reflect-config.json` 显式注册；Hibernate 需 `hibernate.reactive` 或静态代理 hint；**开发期先用 JVM 跑通再切 native** |
| **imgbb 额度/稳定性** | 免费额度有限、偶发不可用 | 上传失败降级为"仅存文字"；监控成功率；额度不足时平滑换 MinIO/COS（前端调用方式不变） |
| **图片压缩兼容性** | 移动端大图、EXIF 旋转、iOS Safari 限制 | Canvas 压缩统一处理 EXIF 方向；设最长边与质量上限；压缩失败回退原图 |
| **金额精度** | float 导致对账误差 | 全程 `NUMERIC(14,2)`，前端展示四舍五入 |
| **JWT 过期策略** | 体验与安全权衡 | 评审确认 access token 有效期与是否需 refresh（见 §8） |
| **Flyway 多环境** | 脚本不一致致环境差异 | dev/prod 共用同一组 `V1__*.sql`，不手改库 |

## 8. 评审议题（已确认决策）

> 已按推荐值确认，评审通过，可进入研发跟进。

1. **JWT 有效期与刷新**：access token **2h**，MVP **不引入 refresh token**，过期重新登录。
2. **分页默认 size**：列表默认每页 **20**。
3. **图片压缩参数**：前端压缩至**最长边 1920、质量 0.8** 后直传。
4. **统一错误码规范**：`code` 约定 —— `0` 成功；`4xx` 业务错误（如 4001 参数错、401 未登录、409 冲突）；`5xx` 系统错误。
5. **删除二次确认**：**前端做二次确认**即可，后端按 `user_id` 强隔离防越权删除。
6. **阶段预算默认值**：新建项目时 8 阶段预算**默认 0**，由用户自填。
7. **装修指南（公开）定位（v0.3 收敛）**：降级为**极简引导**（P0）——8 标准阶段通用科普，未登录可看，作为入口与空态引导；**完整攻略（买什么/找谁/避坑/预算区间）砍掉或延后 P2**，不再投入内容运营；`/api/guides/**` 公开放行、不做 JWT 校验；**v0.3 起攻略与用户实际自定义阶段解绑**（不强行一一对应）。
8. **阶段可自定义（v0.3 新增）**：新建项目默认套 8 标准阶段作模板，**用户可增删改阶段、改阶段名、拖拽排序**（P0）；删除阶段**级联清理其下花销与子项**，前端做二次确认。
9. **阶段内子项清单（v0.3 新增）**：每阶段下用户可自建子步骤/检查项（名称自定义、勾选完成、可排序），与「花销」（采购器材+金额）是两个不同概念，无金额字段。
10. **花销物品名称（v0.3 新增）**：花销记录新增「物品/器材名称」（必填），与「分类」区分，用于记录装修公司给的采购清单；`expenses` 加 `name` 字段（`V3__phase_custom.sql`）。
