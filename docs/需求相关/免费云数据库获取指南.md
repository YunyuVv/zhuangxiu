# 免费云数据库获取指南（测试环境）

> 状态：**已实际接入**。采用 Spring Boot 多 profile 配置：
> - `application.yml` 公共配置 + 默认 `spring.profiles.active: test`
> - `application-test.yml` 写死 **Neon（PostgreSQL）+ Upstash（Redis）** 连接串（端口 9096）
> - `application-prod-docker.yml` 预留生产环境（容器网络 PG/Redis，环境变量注入）

> 本文保留获取步骤（供后续更换 / 重配参考），并说明当前已写入的凭据与运行方式。

## 一、Neon · 获取 PostgreSQL 连接串（参考 / 更换用）

1. 打开 https://neon.tech ，点击 **Sign up**（可用 GitHub / Google 账号登录）。
2. 登录后点击 **New Project**（新建项目）。
   - 地区选 `Asia Pacific (Singapore)` 等就近区域。
   - 项目名随意，如 `zhuangxiu`。
3. 进入项目控制台 **Connection Details**：
   - 复制 **Connection string**，形如 `postgresql://<user>:<password>@<host>/<dbname>?sslmode=require`。
   - 测试/单次连接用 **Direct（直连）**；注意本项目当前用的是 **Pooler（连接池）** 串（URL 含 `-pooler`）。
4. 在 `application-test.yml` 的 `spring.datasource.url` 写入时**需加 `jdbc:` 前缀**。

---

## 二、Upstash · 获取 Redis 连接串（参考 / 更换用）

1. 打开 https://upstash.com ，点击 **Sign Up**。
2. 控制台点击 **Create Database**：名称随意，地区选 `Asia Singapore`，类型 **Redis**（免费 256 MB）。
3. 数据库详情页 **Endpoint** 区域复制 **Endpoint URL**，形如 `rediss://default:<password>@<host>:6379`。
   - 注意是 `rediss://`（带 `s`，强制 TLS）。后端已支持该协议。

## 四、如何运行

```bash
cd server

# 默认（test 环境，连 Neon + Upstash）
mvn spring-boot:run

# 生产（prod-docker 环境，连容器网络 PG/Redis）
mvn spring-boot:run -Dspring-boot.run.profiles=prod-docker
```

- 后端地址：`http://localhost:9096`
- Swagger UI：`http://localhost:9096/swagger-ui.html`
- 启动后 Flyway 会在对应库自动建表。

前端（`web/next.config.mjs`）的 `/api` 代理已指向 `http://localhost:9096`。

## 五、更换 / 重置凭据

- 若密码泄露或需重配：在 Neon / Upstash 控制台 **Reset password / Rotate credentials** 重新生成。
- 把新连接串按第三节格式更新到 `application-test.yml` 对应位置（Neon 记得加 `jdbc:` 前缀）。
- 本仓库当前**不是 git 仓库**；若后续纳入 git，请将含凭据的 `application-test.yml` 加入 `.gitignore`，
  或改为通过环境变量注入，避免凭据随代码外泄。
