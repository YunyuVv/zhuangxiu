└─────────────┘                     └───────────┬──────────┘
                                                │
                       ┌────────────────────────┼────────────────────────┐
                       ▼                        ▼                        ▼
                 ┌──────────┐            ┌──────────────┐        ┌──────────────┐
                 │ PostgreSQL│           │   Redis      │        │  imgbb 图床   │
                 │ (Neon)    │           │ (缓存/会话)  │        │ (图片 URL)   │

## 三、前端技术栈

- **Next.js 15**（App Router）+ **React 19**：SSR/CSR 一体的前端框架。
- 调用后端 REST API，携带 JWT 访问受保护接口。
- 图片走 imgbb，数据库仅存 URL。

## 四、关键约定（跨组件）

1. **表结构只由 Flyway 管**：`ddl-auto: none`，禁止 Hibernate 自动改表。
2. **接口文档由 Springdoc 提供**：`/swagger-ui.html`，后端启动即可访问。
3. **认证用 JWT**：无状态，前端在请求头带 `Authorization: Bearer <token>`。
4. **Native 编译是可选优化**：JVM 模式直接 `mvn spring-boot:run` 即可跑；原生镜像需 GraalVM + 额外反射配置（见 Native 文档与《GraalVM Native 编译踩坑记录》）。
